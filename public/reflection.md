# Reflection

---

### MOBI3002 – Cake Ordering App
- **Learned:** Gained experience using SQLite with Android, building database helpers, designing navigation flows, and considering UI/UX principles throughout the app.
- **Challenges:** Ensuring modularity as the project grew, refining the UI for a smoother user experience, and managing the progression of features.
- **Future Plans:** Use this project as a demo or boilerplate for future Android apps—especially for demonstrating navigation patterns, database handling, and MVVM concepts.

---

### INET2005 – Inventory Management System
- **Learned:** Developed a strong understanding of PHP backend development, Laravel’s MVC architecture, routing, controllers, and Blade templating.
- **Challenges:** Navigating the Laravel ecosystem, configuring controllers, and understanding how the framework organizes application logic.
- **Future Plans:** Containerize the application for easier deployment and potentially create an installer or setup script.

---

### PROG2200 – Snake Game
- **Learned:** Improved knowledge of game logic, collision detection, and structuring game components such as spawners and movement systems.
- **Challenges:** Implementing reliable collision logic, experimenting with asynchronous programming, and managing project scope.
- **Future Plans:** Enhance the visual design and polish the gameplay to make it feel like a complete, standalone game rather than a class project.

---

### PROG2100 – Library Management System
- **Learned:** Applied full OOP principles, worked with date handling, optimized utility functions, practiced separating declarations and implementations, and strengthened habits around modular design and principles like DRY and KISS.
- **Challenges:** Managing time effectively, handling the project’s scope, and maintaining clear separation of concerns.
- **Future Plans:** Expand it into a fully functional, real‑world‑ready application with a more robust feature set and improved architecture.
